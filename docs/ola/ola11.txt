### **Plano de Melhoria: Refinamento do Feedback Visual e Gerenciamento da Fila**

**1. What (O Quê):**
*   **Remover arquivos concluídos da lista "Em Progresso" (segundo bloco).**
*   **Garantir que arquivos concluídos (processados ou ignorados) exibam permanentemente o selo de verificação (checkmark) na "Fila de Processamento" (primeiro bloco).**
*   **Remover o comportamento de fundo verde transitório para arquivos concluídos na "Fila de Processamento" (primeiro bloco), mantendo apenas o selo de verificação.**

**2. Why (Por Quê):**
*   **Melhorar a clareza e precisão da interface do usuário:** Evitar que arquivos já finalizados apareçam como "em andamento", reduzindo confusão.
*   **Fornecer feedback visual consistente e duradouro:** O selo de verificação deve ser o indicador definitivo de conclusão, visível em todos os momentos.
*   **Reduzir a poluição visual:** Eliminar o fundo verde transitório para arquivos concluídos, focando na informação essencial (o selo).
*   **Aprimorar a experiência do usuário (UX):** Tornar o sistema mais intuitivo e fácil de entender o status de cada arquivo.

**3. When (Quando):**
*   **Prioridade:** Alta. Esta melhoria impacta diretamente a usabilidade e a percepção de funcionalidade do sistema.
*   **Prazo:** A ser definido pela equipe de desenvolvimento, mas deve ser implementado o mais breve possível.

**4. Where (Onde):**
*   **Principalmente:** `app/static/js/main.js` (lógica de atualização da UI e gerenciamento das listas).
*   **Possivelmente:** `app/static/css/style.css` (para garantir que o fundo verde não seja aplicado a arquivos concluídos).

**5. Who (Quem):**
*   **Responsável:** Equipe de Desenvolvimento Front-end (JavaScript, CSS).
*   **Colaboração:** Necessária a compreensão da lógica de `TranscriptionManager` no back-end (`app/transcriber.py`) para entender o estado dos arquivos.

2.4. Substitua a função updateStatusStyles:

Finalmente, substitua a função updateStatusStyles para que ela use o conjunto de arquivos concluídos, aplique a classe status-completed e adicione o selo de verificação de forma permanente e sem duplicatas.

JavaScript

    // SUBSTITUA a função updateStatusStyles inteira por esta versão
    function updateStatusStyles(filesInProgress, completedOrSkippedPaths) {
        // Limpa todos os status antigos e ícones para evitar duplicatas
        fileTreeContainer.querySelectorAll('.status-processing, .status-paused, .status-completed').forEach(el => {
            el.classList.remove('status-processing', 'status-paused', 'status-completed');
        });
        fileTreeContainer.querySelectorAll('.folder-status-processing, .folder-status-completed').forEach(el => {
            el.classList.remove('folder-status-processing', 'folder-status-completed');
        });
        fileTreeContainer.querySelectorAll('.fa-check-circle').forEach(icon => icon.remove());

        // Aplica status de processando e pausado nos arquivos
        Object.entries(filesInProgress).forEach(([path, info]) => {
            const fileEls = fileTreeContainer.querySelectorAll(`[data-filepath="${path}"]`);
            fileEls.forEach(el => {
                const statusClass = info.status === 'paused' ? 'status-paused' : 'status-processing';
                el.classList.add(statusClass);
            });
        });

        // Aplica status de concluído (classe e selo de verificação)
        completedOrSkippedPaths.forEach(path => {
            const fileEls = fileTreeContainer.querySelectorAll(`[data-filepath="${path}"]`);
            fileEls.forEach(el => {
                el.classList.add('status-completed');
                if (!el.querySelector('.fa-check-circle')) {
                    const checkmark = document.createElement('i');
                    checkmark.className = 'fas fa-check-circle text-green-600 ml-1';
                    el.appendChild(checkmark);
                }
            });
        });

        // Aplica status em pastas (agora usando a lista completa de concluídos)
        fileTreeContainer.querySelectorAll('div[data-source-path]').forEach(groupContainer => {
            const sourcePath = groupContainer.dataset.sourcePath;
            if (sourcePath === 'avulsos') return;
            
            const filesInGroup = fileQueue.filter(f => f.source === sourcePath).map(f => f.path);
            if (filesInGroup.length === 0) return;

            const inProgressPaths = Object.keys(filesInProgress);
            const completedPaths = Array.from(completedOrSkippedPaths);

            const isAnyInProgress = filesInGroup.some(fp => inProgressPaths.includes(fp));
            const areAllCompleted = filesInGroup.every(fp => completedPaths.includes(fp));

            if (areAllCompleted) {
                groupContainer.classList.add('folder-status-completed');
            } else if (isAnyInProgress) {
                groupContainer.classList.add('folder-status-processing');
            }
        });
    }
